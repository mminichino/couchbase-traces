# Port history

The phase specs that drove the HyperDX-to-Couchbase port (Phases 0 and 5A to
11), moved here from the repository root in v1.1.0 (P10). They record decisions
as they were made and are not kept current; `docs/port-notes.md` records what
changed afterwards, and `docs/v1-release-plan.md` is the current plan. The
master plan they cite, `COUCHBASE_PORT_PLAN.md`, was never committed (Phase 0
waiver).
